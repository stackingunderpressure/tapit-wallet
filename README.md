# tapit-wallet
Sovereign identity wallet. Generates and holds the user's keypair; Merkle holder of the signed attestations that make up their verifiable life. Built on tapit-attest (chassis-inherited, 76 tests green). v1 Phases 1-4: shell + auth, identity + encrypted backup, Layer 2 inter-app signing (Nostr NIP-46), wallet bot. Layer 3 peer network deferred.
