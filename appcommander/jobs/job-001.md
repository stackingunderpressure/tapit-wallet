up and the `tapit-attest` dependency resolves.

## Constraints

- Mobile-first. 375px iPhone is the design target. 44px tap
  targets.
- TypeScript strict. No `any` without a `// reason:` comment.
- The keys-never-leave rule (CLAUDE.md): this job does not touch
  keys at all, but never introduce a code path that could log,
  commit, or transmit one.
- ENV var format: `KEY=` lines only — no values, no placeholders,
  no quotes. No secret values in the repo; track names only.
- Required env names: `SUPABASE_URL`, `SUPABASE_ANON_KEY`.
  `ANTHROPIC_API_KEY` is for the wallet bot — not needed in this
  job.
- Do NOT re-implement anything in `tapit-attest`. Inherit it.

## Stack defaults (from CLAUDE.md)

- React 18 + Vite + TypeScript + Tailwind
- Supabase (Postgres + Auth + Edge Functions) for backend
- Netlify for hosting
- `tapit-attest` (chassis-inherited) for the wallet core
