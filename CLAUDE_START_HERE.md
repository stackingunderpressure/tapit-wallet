## The thing you must never get wrong

The user's private key never leaves the wallet unencrypted. It is
never an env var, never logged, never committed, never sent to a
host in plaintext. Backup and sync move only ciphertext. If a
change you are about to make would put a key anywhere else —
stop.

## tapit-attest is inherited, never re-implemented

The chassis carries the `tapit-attest` library at the repo root
as `tapit-attest/`. It is the signed-attestation primitive AND
the `Wallet` core object (Layer 1 — already built). This app
consumes it as a `file:` dependency. Do NOT re-implement the
envelope, the signing, or the `Wallet` class. One library, one
envelope standard — that is the compatibility guarantee that lets
every app and every wallet interoperate.
